# Volley 5-1 en 3D

Terrain 3D interactif pour comprendre la formation 5-1 au volley-ball : les 6 rotations, en attaque (réception, passe, attaque), en défense (contre, défense, contre-attaque) et en rally aléatoire.

## Ouvrir l'application

- En ligne : https://ygbrs.github.io/learn_volley_5-1_3d_animation/volley_3D.html
- En local : ouvrir `volley_3D.html` dans un navigateur (connexion internet nécessaire pour charger three.js).

## Fonctionnalités

- 6 rotations (P1 à P6), modes Attaque, Défense et Rally aléatoire (1 à 30 tours)
- Mise en avant de ton rôle, trajet au sol, conseils à chaque étape
- Bulle d'info au survol ou au toucher d'un joueur
- Caméras : vue joueur, vue tactique, côté, adverse, suivi du joueur
- Utilisable sur ordinateur et sur smartphone

## Mettre à jour

Remplacer `volley_3D.html`, puis :

```
git add volley_3D.html
git commit -m "Mise à jour de l'application"
git push
```

GitHub Pages republie le site automatiquement en une à deux minutes.
